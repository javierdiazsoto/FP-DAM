# Gestión de alquiler de videojuegos

Este proyecto consiste en desarrollar una aplicación de escritorio en Java utilizando NetBeans, que permite gestionar el alquiler y la devolución de videojuegos.

La aplicación permite registrar usuarios, añadir videojuegos, controlar el stock disponible según la plataforma y gestionar los alquileres. También permite consultar los alquileres activos y devueltos, controlar las fechas de devolución y evitar operaciones incorrectas, como alquilar un juego sin stock o eliminar usuarios y videojuegos que tienen alquileres activos.

El objetivo principal es crear una aplicación sencilla y funcional, aplicando los conocimientos adquiridos durante el ciclo de FP Superior.
